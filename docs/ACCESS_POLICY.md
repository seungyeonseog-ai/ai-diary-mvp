- 체험 중 추가대화·응원·주간의 공통 권한을 반환하고 종료 시 무료로 판정한다. 과거 plan 값이나 유료 기간이 권한을 늘리지 않는다. 유료 부여·변경·해지 함수와 모델은 제외한다.

- 기존 account_access.plan은 첫 이행의 NOT NULL 컬럼 호환용 고정 free다. 운영 DB의 빈 과거 컬럼/테이블을 파괴적으로 삭제하지 않는다.
- 원문·일기·기존 가입/시각/사용량을 바꾸지 않는 추가형 이행이다. 복사본에서 백업·기존 모든 테이블 값 보존·반복 실행을 검증한다.

검사: `python -B -m unittest tests.test_access_policy tests.test_writing_flow -q`.
운영 DB 읽기 전용 복사본: `python -B -m tools.migrate_access --database <기존DB경로> --verify-copy`.

이 커밋은 묶음1만 포함한다. 사용량 성공차감(2), 생성후대화/화면(3), 폐기(4), 의향저장/이용권(5), 가입안내(6), 예약(7), 주간(8), 최종종단(9)은 후속이다. 실제 외부 AI 호출은 이 묶음에 필요하지 않다.
