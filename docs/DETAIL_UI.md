# 서재 더보기·빈 상태·알림 컴포넌트 통일

2026-11-03 (Asia/Seoul). 사용자 승인 구성으로 구현했다. 직전 사진 검토/수정 보류 요청은 이번 명시 수정 요청으로 해제됐다.

## 사용자에게 보이는 변화

- 지난일기 더보기: 서재 대표 이미지·소개 문구·큰 제목 제거. `‹ 서재로 돌아가기` 아래에 달력/목록 탭과 실제 기록을 바로 표시한다. 서재 책장 기본 화면의 대표 이미지는 유지한다.
- 주간 더보기: 큰 소개 제목 제거, 같은 복귀 링크/여백/선택형 탭. 실제 기간은 탭 아래에 표시하고 점 클릭 안내는 그래프 위에 둔다. 자료가 없는404일 때는 세 탭 본문·안내·고정 키워드 제목을 모두 숨기고 기존 대시보드 문구를 가운데 표시한다. 현재 어두운 배경 유지. 최초 로딩에도 본문을 숨겨 무자료 설명이 잠깐 노출되지 않는다. 중복 날짜·503 등 오류는 빈 상태로 감추지 않고 오류/재시도로 구별한다. 날짜 중복 검사 유지.
- 응원 더보기: 같은 복귀 링크/여백/탭 아래에 편지를 바로 표시한다. 오늘편지·보관함·알림에서 선택한 편지 모두 별도 본문 모달 없이 읽는다. 일기 상세와 동일한 lamp-default-v1.png를 본문 오른쪽 위에 배치한다. 보관/폐기/보관함 삭제는 기존 API로 처리하며 확인·오류·재조회·계정 격리를 유지한다. 알림의 과거편지 선택은 '받은편지'로 표시해 '오늘'과 구분한다. 선택 주소를 유지해 새로고침해도 보관함/편지 선택을 복원한다.
- 응원 무자료: 오늘 내용/불필요 안내 나열 대신 중앙 잠금 안내. 보관함도 빈 상태를 별도로 표시한다. 새 대화를 입력하거나 새 AI 생성을 이 화면에서 자동 실행하지 않는다.
- 공통: 왼쪽 종 아이콘+알림 문구. 계정 캐릭터의 동작을 공통 daily 진입점에서 연결해 주간·응원에서도 정상 동작한다. 기존 페이지별 핸들러와 중복 실행되지 않게 캡처 단계에서 처리한다. 공통 UI 대화상자/알림·설정 패널/일일 상세/연월 선택은 오른쪽 위 원형×로 닫는다. 닫기 선택 버튼은 공통 대화상자에서 제외하고 취소/확인 등 의미 있는 작업은 유지한다. 확인창의 ×/Escape는 취소이며 실행 승인으로 취급하지 않는다.
