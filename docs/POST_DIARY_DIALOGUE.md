# 묶음3 — 일기 후 추가 대화

- 초안·저장·기존 일기와 기본 대화 성공 기록 없는 이전 일기에서도 남은 추가 횟수만 사용한다. 일기 제목·본문·버전은 대화로 변경하지 않는다.
- 입력·전등·두 선택 버튼·다른 탭 메시지 갱신을 연결했다. 오늘 일기 보기는 기존 결과를 열고, 추가 답변 후에는 일기 재생성을 묻지 않는다.
- 자동 Python 60개와 프론트 2개 파일 PASS. 실제 Uvicorn 8018 HTTP 7항목 PASS: 초안/저장 후 추가, 일기불변, 저장실패 재시도·생성재호출 없음, 소진, 캐시·중복생성, 계정격리.
- 실제 브라우저: 구형9b2로 기본답변·초안생성/저장 후 새10c3 화면으로 이동, 추가대화2→1→0·입력/전등잠금·기존 일기 열람 PASS. 초안 이탈 방지로 reload가 적용되지 않은 경우 저장/제품 내 이동 후 새 파일 적용을 확인했다.
- AI·검색·시각은 합성이며 외부AI0, 실제8000DB 시험쓰기0. 실제 외부AI/Worker전달/장기간 관찰은 별도 범위.
- 검사 도구 수정: 합성 lamp는 실제 화면과 동일한 SSE 사용, 격리 재실행의 요청ID는 고유하게 분리. 검사 중 구형 파일 임시교체와 프론트 검사가 겹친 실패는 새파일 복구 후 통과. 제품 오류로 기록하지 않는다.
