# 측정 전 UI 조정 — 2026-11-04

## 적용 동작

- 가입 성공/실패를 공통 알림으로 표시하고 처리 중 중복 제출을 막는다.
- 첫 안내는 체험 안내의 다음→응원 시간의 완료로 구성한다. 중간 기능 소개 알림은 제거한다. 이 두 단계는 X와 Escape로 건너뛰지 않는다. 응원 설정 조회 실패 시 다시 불러오기, 저장 실패 시 입력 유지/재시도를 제공한다. 안내 완료는 기존 서버 저장 성공 기준을 유지한다.
- 체험 종료일은 기존 계정별 서버 값을 표시한다. 가입일 포함7일 뒤00:00 KST 정책이며 정확168시간으로 변경하지 않았다.
- 홈페이지 이름 위와 공간의 기존 아바타 아래에 실제 권한 상태 배지를 표시한다. 무료 계정이 슈퍼패스 선호를 저장했다는 이유로 슈퍼패스로 표시하지 않는다. 전체 폭 체험 배너와 왼쪽 이용권 메뉴는 제거한다.
- 왼쪽 아바타는 기존 account-avatar-v1.png를 유지한다. 남은 대화는 우측 위의 기본 전등1칸/추가 맨전구2칸과 숫자로 표시한다. 사용하면 해당 불이 꺼지며 서버 이용량 계산은 변경하지 않았다.
- 전등 클릭 시 기본·추가 대화 모두 답변 요청/더 말하기를 선택한다. 더 말하기는 입력/사용량을 유지한다. 소진된 전등도 클릭할 수 있으며 소진 안내만 띄우고 AI를 호출하지 않는다.
- 일기 제목 옆 저장 상태는 보관중으로 표시한다. 수정 취소 알림은 설명 없이 수정하기(편집 유지)/취소(수정 취소)로 구성한다.
- 하단의 더 이야기하기 버튼은 제거한다. 저장한 일기는 서재에서 열며, 미저장 초안만 작성 중인 일기 열기로 재진입한다. 입력창/전등이 추가 대화 경로이고 일기 생성 버튼은 생성 전 단계에만 제공한다.
- 공통 JS 모듈과 템플릿의 버전 주소를 함께 갱신한다. 이미 열린 화면은 새로고침 후 적용된다. API 계약/DB/이용권 권한은 변경하지 않는다.

## 검증

- access/onboarding/daily/post-diary/writing-stream/UI-contract 회귀57개 통과.
- 자산 추가 후 UI-contract4개: 이미지 바이트/해시·페이지/계정 격리·원문 입력 계약 통과.
- writing_ux_frontend: 사진/수정/일기·선택 분기/소진 클릭/계정 변경 회귀 통과.
- space_stream_frontend: 첫 말풍선/후속 청크/저장 필수/오류/순서/계정 변경 통과.
- ui_dialog_frontend: 필수 단계 닫기 방지·알림 직렬화·다음 일반 알림의 닫기 복원 통과.
- 실제 브라우저는 tests.browser.ui_polish_server의 독립 DB/합성 AI에서 가입/온보딩/배지/전등 요청·추가소진/일기 편집·취소/저장을 확인한다. 원본 DB·검색 색인에 시험쓰기하지 않는다. 외부 AI 비교 호출은 별도 승인된 직접 합성요청이며 이 UI 통합 검사와 구분한다.

## 남은 논의

- 가격 확정 전 만료 후 조합 선택 모달은 미구현이다. 이용권 메뉴는 제거했지만 기존 /passes URL과 선택 API는 교체 전 보존한다. 기존 무료 유지 선택·권한 불변 정책도 유지한다.
- 짧은 공감 대화의 추론 없음 적용은 진단 후 별도 사용자 선택을 기다린다. 현재 제품의 모델·추론 설정은 변경하지 않았다.

## 배포 검사 범위

Dockerfile은 static/templates 전체를 COPY한다. 이번에는 Compose/의존성/기동/환경/DB/볼륨/API 계약 변경이 없어 전체 Compose 회귀를 반복하지 않는다. 최종 배포 이미지에서 새 정적 자산과 버전 주소·기존 열린 화면 새로고침을 확인한다. 이후 가격 기록 때문에 DB 이행 또는 권한 정책을 변경하게 되면 그 영향 범위를 별도로 검사한다. 클라우드 첫 표시/속도·실제 예약시각/자연기간은 기존 후속 검사로 유지한다.

후속 하단 버튼 정리: JS 상태 회귀 통과. 새 버튼 흐름의 실제 브라우저 재확인은 도구 CDP 시간 초과로 완료하지 못했다. 앞서 확인한 가입/온보딩/횟수/저장 화면 검증과 구분한다.
