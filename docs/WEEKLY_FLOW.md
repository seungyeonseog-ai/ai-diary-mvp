# 주간 3탭·일일 감정 분석 — 7번

2026-11-03. 확정근거: 상위 outputs/generation-rules-2026-11-02.md 최신후속절. 이전 3일째 즉시생성안/미사용7건소비는대체한다.

## 실행 규칙

- 주기 첫날은 가입일이 아니라 대화 시작일. 신규기능 적용 후 첫 사용자 대화의 KST 날짜를 anchor_date로 영속 저장한다. 과거DB를 적용 즉시 유료AI로 소급 분석하지 않는다. 이후 7일 고정기간을 연속으로 점검한다.
- 일일 분석은 해당 날짜00:00이상23:50미만 사용자 대화를 고정원본ID로 등록한다. 입력수250조건없음. 원본0이면생성없음. 폐기일기 상태로 원문을 제외하지 않는다. 23:50이후 대화는 그날 일일분석에추가하지않고다음날로이월하지않는다.
- 23:50후작업이끝나도 date_str/분석자료timestamp는원래날짜이며작업로그의실행시각과분리한다. 세션기억요약/응원예약/자정기억은이규칙의영향을받지않는다.
- 7일째23:50자료가마감된후3~7일분일일분석이성공하면감정흐름/감정해석/키워드인사이트한묶음생성. 3일미만이면그기간결과없이다음7일로넘어간다. 마지막10분대화만있는날은분석자료0이므로가짜분석/0점으로채우지않는다. 이경계는UI/사용자관찰후추가평가가능하다.
- 주간생성후추가대화는기존결과변경안함. 기간간날짜재사용없음. 미완료일일분석이있으면성공할때까지그기간주간은대기한다. 서버중단도기존날짜경계로복구한다.
- Beat60초점검은등록/복구용이며논리AI작업이매분생기는것아님. 구형일일저장이벤트의미사용7건자동생성은차단한다.
