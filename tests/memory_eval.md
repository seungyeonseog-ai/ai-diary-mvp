# MVP V0.2 기억력 내부 평가

기준 제품 커밋은 `479882e`다. 이 묶음은 V0.2 후보를 내부에서 비교하기 위한 실험 코드다. 앱 실행 경로에서 실험 모듈을 불러오지 않는다.

## 실행

저장소 루트에서 실행한다.

```powershell
$env:PYTHONIOENCODING = 'utf-8'
./.venv-local/Scripts/python.exe -B -m tests.run_memory_eval
./.venv-local/Scripts/python.exe -B -m tests.run_memory_eval --report memory-eval-report.json
```

고정된 합성 Top12를 전등의 실제 `memory_context`에 공급한다. A는 현재 선별기, B는 세션마다 최고 점수 문서 한 개를 남긴 후 기존 버킷 선별기를 호출한다. 각 조건의 선택 슬롯과 본인 요약 전달 결과를 기록한다. 계정끼리 같은 세션 ID를 사용해 다른 사람의 요약과 섞이는지도 확인한다. 순위를 고정한 실험이라 검색 엔진의 실제 순위·미래 필터·모델 답변 점수는 별도 검증 대상이다.

## 합성 자료와 채점표

4계정에 각각 과거 5일의 사건·원래 일정·정정·비슷한 다른 사건·회상 질문을 넣었다. 평가 기준일은 11월 7일이며 11월 8일 행은 미래 표시용이다. 개발 20문항과 최종 20문항은 계정으로 분리한다. 각 묶음은 정답형 15문항과 회상 불필요·불확실 문항 5개다. 고정 후보는 중복 압박이 발생하도록 구성했으므로 결과는 조건 재현 증거로만 사용한다. 문항별 기대 세션·허용 표현·금지 사실은 `memory_eval_cases.py`에 있다.

| 점수 | 적용 |
| --- | --- |
| 2 | 질문에 필요한 사실과 관계를 모두 전달하고 금지 사실이 없다. ‘초록 장갑’과 ‘녹색 장갑’, 이름 뒤 호칭, 다른 어순, 자연스러운 요약은 허용한다. 최초 요일과 정정 요일을 둘 다 묻는 문항은 순서까지 맞아야 한다. |
| 1 | 틀린 사실 없이 일부만 전달한다. 색이 필수인데 ‘장갑’만 말하거나, 최초와 변경 중 하나를 생략하는 경우다. |
| 0 | 핵심 사실을 틀리게 말하거나 지어내거나 질문에 필요한 사실을 하나도 전달하지 못한다. 정정 순서 뒤바뀜, 타인·미래 표식 노출은 다른 사실이 맞아도 0점이다. |

표현 오차는 뜻이 같을 때 허용한다. 이 세트의 물건·색·요일·인물에는 임의의 수치 또는 시간 오차를 허용하지 않는다. 유보 문항에서 ‘지금 기록만으로는 잘 모르겠어’는 2점으로 인정한다. 문항별 1점 조건은 그 문항에서 일부 기대 행동만 충족했을 때 적용한다.

실제 모델 평가 시 합성 입력과 A/B의 `past_references`를 같은 모델·생성 설정·전등 지시문에 넣는다. 평가자는 조건명·검색 목록을 가린 답변과 문항 기준만 먼저 채점한다. 결과표에는 다음 열을 쓴다.

| 문항 | 가림 답변 ID | 점수 0/1/2 | 맞춘 필수 사실 | 생략·모순·창작 | 판정 메모 |
| --- | --- | --- | --- | --- | --- |
| M301 | 임의 ID |  |  |  |  |

채점 후 조건을 열어 완전 정답 순증, 부분점수 변화, 근거 누락 회복, 새 오답을 집계한다. 핵심 기준은 최종 15문항 중 완전 정답 13개 이상 및 순증 2개 이상이다. 기준선이 14개 이상이면 성공 건수를 유지하면서 중복으로 놓친 사례가 회복됐는지 확인한다. 완전 정답과 부분 정답은 따로 보고한다. 전체 기억력 결론은 실제 답변 비교와 회귀 확인 뒤 내린다.
